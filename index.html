Ориентирование

Приложение для спортивного ориентирования по GPS

Позволяет отмечать пикеты, задавать азимут и расстояние до следующей точки, вести трек движения, поворачивать карту по курсу и сохранять прогресс при закрытии.

Основные возможности

  • Отметка текущего положения кнопкой «Я здесь»
  • Расчёт следующей точки по азимуту и расстоянию
  • Подтверждение взятия пикета кнопкой «Пикет найден»
  • История маршрута с цветовой разметкой участков
  • Авто-поворот карты по направлению движения
  • Компас устройства с указанием на цель
  • Автосохранение в память телефона
  • Экспорт и импорт данных в JSON
